# HJ Security Solutions website

A responsive, multi-page website for a UK security services brand. This repository contains the public-facing frontend built with Next.js and TypeScript.

## Pages

- Home and services
- Our approach and company information
- Careers and contact

## Preview

[View the live website](https://hj-security-solutions.vercel.app)

## Run locally

1. Install dependencies with yarn install.
2. Start the development server with yarn dev.
3. Open http://localhost:3000.

The repository demonstrates frontend page composition, responsive layout, navigation, and deployment. Content on the live website represents the brand; this code repository is not evidence for its commercial or accreditation claims.
